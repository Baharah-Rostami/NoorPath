## 📖 About

**NoorPath** is a responsive career opportunity platform designed to connect students and young professionals with valuable opportunities.

Users can browse jobs, internships, scholarships, and other career opportunities, save their favorites, search and filter listings, and even submit new opportunities through a validated form.

The project was built to demonstrate modern frontend development practices using the latest React ecosystem.

# 🚀 Getting Started

Clone the repository

```bash
git clone https://github.com/Baharah-Rostami/NoorPath.git
```

Navigate into the project

```bash
cd noorpath
```

Install dependencies

```bash
npm install
```

Run the development server

```bash
npm run dev
```

Open

```text
http://localhost:3000
```
